# Contact Management System

A web-based Contact Management System that allows users to securely manage their personal contacts.

## Technologies Used

### Backend
- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- Maven

### Frontend
- React.js
- Vite
- Axios
- React Router

### Database
- Microsoft SQL Server
